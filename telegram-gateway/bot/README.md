# Telegram Movie Bot (Gateway Service)

## 1. Название и назначение сервиса
**Название:** Telegram Movie Bot
**Назначение:** Основной шлюз (Gateway) и пользовательский интерфейс в микросервисной архитектуре приложения для поиска фильмов. Сервис предоставляет Telegram-бота, через которого пользователи могут искать информацию о фильмах, оставлять текстовые отзывы, ставить оценки и просматривать свои ранги.
**Основные функции:**
* Умный поиск фильмов с агрегацией данных из нескольких источников.
* Система пользовательских оценок (1-5 звезд) и текстовых рецензий.
* Геймификация: присвоение рангов пользователям на основе их активности (количества отзывов).
* Поиск по режиссеру, студии и просмотр наград.
* Кэширование запросов к внешним API в локальную БД для оптимизации нагрузки.

## 2. Архитектура и зависимости
* **Технологии и фреймворки:** PHP 8.4, Laravel 11/12, Eloquent ORM.
* **Взаимодействие с другими микросервисами:**
  Сервис выступает оркестратором и обменивается данными по HTTP REST API со следующими внутренними микросервисами:
  * `kinopoisk_api` (получение данных о фильме и жанрах с Кинопоиска).
  * `imdb_api` (получение данных о бюджете, режиссере, студии и наградах из OMDb/IMDb).
* **Используемые внешние/внутренние сервисы:** * **PostgreSQL 17** — реляционная база данных для хранения информации о пользователях, фильмах, отзывах и рангах.
  * **Telegram Bot API** (Long Polling) — для получения и отправки сообщений пользователям.

## 3. Способы запуска сервиса

**Запуск через Docker (рекомендуемый способ):**
Проект поставляется с готовым `docker-compose.yml`. Для запуска всего кластера (Бот + БД + Микросервисы API + Redis) выполните в корневой директории:
```bash
docker-compose up -d --build
```
*Docker самостоятельно установит зависимости (composer install), накатит миграции и запустит воркер `php artisan telegram:poll`.*

**Альтернативный локальный запуск (без Docker):**
Если база данных и микросервисы уже запущены отдельно:
```bash
composer install
php artisan migrate --force
php artisan telegram:poll
```

**Описание переменных окружения (`.env`):**
Для корректной работы сервиса бота требуется создать файл `.env` со следующими переменными:
* `TELEGRAM_BOT_TOKEN` — уникальный токен бота, полученный от @BotFather.
* `DB_CONNECTION=pgsql` — драйвер базы данных.
* `DB_HOST=db` — хост базы данных (имя контейнера в Docker).
* `DB_PORT=5432` — порт БД.
* `DB_DATABASE=Cinema_bd` — название базы данных.
* `DB_USERNAME` / `DB_PASSWORD` — логин и пароль от PostgreSQL.
* `IMDB_SERVICE_URL=http://imdb_api:8002` — URL для связи с микросервисом IMDb внутри Docker-сети.
* `KINOPOISK_SERVICE_URL=http://kinopoisk_api:8001` — URL для связи с микросервисом Кинопоиска внутри Docker-сети.

## 4. API документация
Поскольку данный сервис представляет собой интерфейс Telegram-бота (Long Polling), его публичным "API" являются команды, доступные пользователям в чате.

**Основные команды (эндпоинты бота):**
* `/start` — Инициализация пользователя, регистрация в БД и выдача стартового меню.
* `/search [название фильма]` — Поиск фильма. Если фильм не обновлялся в локальной БД более 7 дней, бот запрашивает актуальные данные у `kinopoisk_api` и `imdb_api`.
* `/director [имя фамилия]` — Поиск фильмов указанного режиссера по локальной БД.
* `/studio [название]` — Поиск фильмов, выпущенных определенной студией.
* `/awards [название фильма]` — Вывод списка наград агрегированных из IMDb для конкретного фильма.
* `/status` — Просмотр профиля пользователя (текущий ранг и количество написанных отзывов).
* `/my_reviews` — Вывод списка всех оценок и рецензий, оставленных пользователем.
* `/find_review [название фильма]` — Поиск собственного отзыва на конкретный фильм.

*Для взаимодействия с меню бот также генерирует и обрабатывает `callback_data` (rate, mark, write, fact, read).*

## 5. Как тестировать
Для запуска тестов (Unit/Feature) средствами фреймворка Laravel (PHPUnit/Pest), выполните следующую команду внутри запущенного контейнера бота:

```bash
docker exec -it laravel_bot php artisan test   
```
